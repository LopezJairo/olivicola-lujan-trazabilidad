# 04 - Manual del operario

[[Olivícola Luján/00 - Índice general|← Volver al índice general]]

## Antes de empezar

Si arriba dice **Modo demostración**, los datos pertenecen a este navegador y pueden ser ejemplos. Pedile al responsable que confirme el entorno habilitado antes de cargar inventario oficial.

## Consultar un tambor

1. Abrí **Escanear tambor**.
2. Hacé clic en el campo del código si el cursor no está allí.
3. Apuntá el lector a la etiqueta.
4. Esperá a que se abra la ficha.
5. Confirmá el número, producto y ubicación.

Sin lector, escribí el número, por ejemplo `T000001`, y presioná Enter o **Buscar tambor**.

## Registrar un tambor

1. Desde Inicio, elegí **Registrar nuevo tambor**.
2. Seleccioná producto, presentación, variedad, calibre y calidad.
3. Escribí el lote.
4. Indicá peso neto en kilogramos y fecha de ingreso.
5. Completá fecha de elaboración si corresponde.
6. Elegí ubicación y estado.
7. Agregá observaciones si hacen falta.
8. Presioná **Registrar tambor** y esperá el mensaje de confirmación.

El sistema genera el número y el código. No inventes una opción si falta: pedí que la agreguen a Configuración.

## Registrar un movimiento

1. Abrí la ficha del tambor correcto.
2. Elegí **Registrar movimiento**.
3. Seleccioná qué ocurrió y la nueva ubicación.
4. Elegí un nuevo estado solo si corresponde.
5. Agregá observaciones y presioná **Guardar movimiento**.
6. Revisá que la ficha muestre la ubicación esperada.

## Corregir información

Abrí la ficha y elegí **Editar información**. Corregí los datos y guardá. La información anterior de los campos modificados queda en el historial. Si cambian las características que forman el código, consultá con el responsable para reemplazar la etiqueta.

## Obtener una etiqueta

Desde la ficha, elegí **Ver etiqueta** y luego **Imprimir etiqueta**. Para varios tambores, usá **Imprimir etiquetas**, seleccioná los registros y configurá las medidas del papel. Ver [[Olivícola Luján/08 - Identificación y etiquetas|08 - Identificación y etiquetas]].

## Problemas frecuentes

| Problema | Qué hacer |
|---|---|
| El lector no escribe | Volver a hacer clic en el campo; comprobar conexión USB. |
| Escribe pero no abre la ficha | Revisar que el lector envíe Enter al terminar. |
| Código desconocido | Revisar la etiqueta o buscar el número del tambor en Inventario. |
| Falta una ubicación o variedad | Pedir al administrador que la agregue o active. |
| No se abre impresión | Habilitar ventanas emergentes para la app y reintentar. |
| Error al guardar | Leer el mensaje; no suponer que el registro quedó guardado. |
| Mensaje de guardado parcial | No repetir la operación; avisar al administrador para revisar ficha e historial. |

## Precaución operativa

La eliminación es irreversible desde la aplicación. Para una corrección normal se debe usar Editar, no eliminar y volver a cargar. La política sobre quién puede eliminar debe acordarse con la empresa.
